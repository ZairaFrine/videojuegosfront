####################
### INTRODUCCIÓN ###
####################


Instala A-ngular
npm install -g @angular/cli

Crea la carpeta de trabajo
ng new videojuegos-front

Iniciar Angular, uno u otro, NO los dos....
npm start
ng serve

Acceso desde browser
http://localhost:4200

Abrir /src/app/app.html


Crear servicios
ng g s services/videojuegos --skip-tests

Abrir Carpeta
/src/app/app.config.ts

Abrir Carpeta
/src/app/services/videojuegos.ts

Abrir Carpeta
/src/app/app.ts

Abrir Carpeta
/src/app/app.html

levantar back y front:
npm start
